# PHASE 4: DATABASE MANAGEMENT & SQL CLINICAL ANALYSIS:

## OVERVIEW:
This phase focuses on executing structured Exploratory Data Analysis (EDA), data verification, and advanced clinical risk stratification on the cleaned anesthesia dataset containing one thousand ten patient records using MySQL and DBeaver.

## KEY TECHNICAL STEPS AND IMPLEMENTATION:
* **Database and Table Verification:** Checked schema integrity, confirmed total row counts, and verified successful data import into the database.
* **Basic Filtering and Profiling:** Filtered patient cohorts based on fundamental clinical parameters including age, gender, and surgical categories.
* **Aggregations and Calculations:** Computed average post-operative recovery durations in PACU minutes, body mass index distributions, and overall surgical frequencies.
* **Risk Stratification and Segmentation:** Utilized advanced database query clauses for multi-level risk categorization and isolated high-risk grades associated with prolonged recovery times.

## TECH STACK AND TOOLS:
* **Database Management System:** MySQL
* **SQL Integrated Development Environment:** DBeaver
* **Dataset Used:** Cleaned anesthesia dataset with one-hot encoded categorical clinical variables
