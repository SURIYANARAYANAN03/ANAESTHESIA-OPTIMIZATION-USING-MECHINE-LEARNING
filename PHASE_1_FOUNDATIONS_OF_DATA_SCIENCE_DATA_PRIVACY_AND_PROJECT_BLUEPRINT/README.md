# Anaesthesia Optimization Using Machine Learning

> *"Engineering clinical precision from data — the foundational first gear of my data science journey."*

🩺 **Data-Driven Clinical Analytics for Anaesthesia Optimization** | Leveraging Python, Advanced Statistics, SQL, and Tableau to transform pre-operative patient insights into actionable surgical intelligence.

---

### 🎯 Executive Overview
Modern healthcare relies heavily on precision. Selecting the optimal type of anaesthesia and determining precise dosage levels based on pre-operative (pre-op) patient findings is critical for surgical safety and rapid recovery. This end-to-end Data Science project demonstrates a rigorous, multi-phase analytical pipeline designed to solve real-world clinical challenges while maintaining strict data privacy standards.

---
